Case Briefing START HERE

Two laws, one lesson. HMDA requires lenders to collect and report mortgage data so regulators can detect discriminatory patterns. The Fair Housing Act prohibits discrimination in housing transactions including lending. Together they form the cornerstone of fair lending enforcement.

EXHIBIT A
What Is HMDA?
Home Mortgage Disclosure Act. Requires mortgage lenders to collect and report data on loan applications. Purpose: enable regulators to identify potential discrimination and monitor lending patterns.
Data transparency
Exam note: HMDA does not make lending decisions — it collects data for ANALYSIS. A disparity in HMDA data triggers investigation but is not itself proof of discrimination. HMDA is the starting point for fair lending examination, not the conclusion.

EXHIBIT B
Fair Housing Act — 7 Classes
Race · Color · National Origin · Religion · Sex · Familial Status · Disability. Prohibits discrimination in selling, renting, and financing residential property.
7 protected classes
Key distinction: Familial status (having children under 18) and Disability are FHA-protected but NOT ECOA-protected (ECOA has age and marital status instead). The exam tests which classes belong to which law constantly.

EXHIBIT C
HMDA Action Codes
Code 1=Originated · Code 2=Approved not accepted · Code 3=Denied · Code 4=Withdrawn · Code 5=Incomplete · Code 6=Purchased by institution. Report the outcome that actually occurred.
Memorize codes
Exam trap: Code 2 = lender APPROVED but borrower did not accept (walked away after approval). Code 4 = borrower WITHDREW before a decision. These are frequently confused. The distinguishing factor: who stopped the process — the lender (denial) or the borrower (withdrawal)?

FILE 001
Redlining
Refusing to lend in certain geographic areas based on the racial composition of those areas. BOTH the FHA Section 3604 AND ECOA prohibit redlining. HMDA data is used to detect it.
Illegal practice
Exam note: Redlining is identified by comparing a lender's lending patterns to demographic maps. If a lender consistently avoids majority-minority neighborhoods while serving similar white neighborhoods, HMDA data will reveal the pattern — triggering a fair lending examination.

FILE 002
Steering
Directing borrowers toward or away from certain neighborhoods or loan products based on their race, ethnicity, or other protected class. FHA Section 3604(e) prohibits steering.
FHA violation
Exam note: Steering has two forms: (1) geographic steering — directing buyers to neighborhoods based on race; (2) product steering — directing certain groups to subprime/HOEPA products when they qualify for prime. Both violate FHA and potentially ECOA.

FILE 003
Blockbusting
Using racial change in a neighborhood to induce panic selling. "The neighborhood is changing — you should sell now before property values drop." Violates Fair Housing Act Section 3604(e).
FHA violation
Exam note: Blockbusting is primarily a real estate agent issue but mortgage professionals can be implicated if they participate in the scheme. It is the deliberate exploitation of racial fear to generate real estate transactions.

FILE 004
HMDA Face-to-Face Collection
For in-person applications, MLO must: (1) ask the borrower to self-identify race/ethnicity, and (2) if borrower declines, record BOTH the refusal AND their visual observation of the borrower's apparent characteristics.
Visual observation
Exam trap: Visual observation is REQUIRED for face-to-face applications when borrower refuses to self-identify — NOT optional. For non-face-to-face (phone/online), visual observation is impossible, so "information not provided" is recorded instead.

FILE 005
FHA Advertising — Section 3604(c)
Ads cannot indicate any preference, limitation, or discrimination based on protected classes. Applies to language, human models, and media selection. ALL-white photo models in all marketing signals exclusion.
Ad discrimination
Exam note: HUD guidelines require advertising models to reflect the racial/ethnic diversity of the community. Using exclusively one racial group in all marketing materials indicates a preference that violates FHA Section 3604(c) — even without explicitly discriminatory language.

FILE 006
Disparate Impact Under FHA
A neutral policy with a disproportionate adverse effect on a protected class can violate the FHA even without discriminatory intent. Statistical analysis of HMDA data is the primary detection tool.
No intent needed
Three-step test: (1) Does the policy have disparate impact on a protected class? (2) Is the policy justified by a legitimate business necessity? (3) Could a less discriminatory alternative achieve the same result? All three steps matter.

FILE 007
HMDA Reporting Threshold
Generally applies to lenders that originate at least 25 covered closed-end loans OR 100 covered open-end lines in each of the two preceding calendar years and meet other criteria.
Who must report
Exam note: Small lenders below the threshold are generally exempt from HMDA reporting. However, the exam typically assumes lenders ARE subject to HMDA and focuses on HOW to report rather than WHEN reporting applies.

FILE 008
Familial Status Protection
Familial status = having children under 18 in the household. Cannot discriminate against families with children in housing or mortgage lending. Exception: legitimate 55+ senior housing communities.
FHA only class
Exam trap: "No children allowed" or "adults only" advertising is ILLEGAL under FHA familial status protection — UNLESS the community qualifies as a legitimate 55+ senior housing community under the Housing for Older Persons Act (HOPA). Age-restricted communities have a narrow, documented exemption.

KEY TAKEAWAYS

  • FHA: 7 classes including familial status and disability
  • ECOA: 8 classes including marital status and age
  • HMDA codes 1-6 — know each one cold
  • Steering: directing based on protected class = FHA violation
  • Redlining detected through HMDA geographic patterns
  • Disparate impact can violate FHA without intent

EXAM TRAPS

  • Code 2 vs Code 4 — who stopped the process?
  • FHA vs ECOA — which class belongs to which law
  • Visual observation required face-to-face only
  • All-white photos in ads = FHA 3604(c) violation
  • HMDA disparity triggers investigation, not automatic violation
  • 55+ communities have HOPA exemption from familial status
