HMDA — Home Mortgage Disclosure Act

HMDA requires mortgage lenders to collect and report data on loan applications. Purpose: enable regulators to identify potential discrimination and monitor lending patterns. Implemented by Regulation C, enforced by the CFPB. HMDA does not make lending decisions — it collects data for analysis.

HMDA Action Codes

CodeMeaningWho Stopped It?
1Loan OriginatedN/A — loan closed
2Approved but Not AcceptedBORROWER (after approval)
3Application DeniedLENDER
4Application WithdrawnBORROWER (before decision)
5File Closed for IncompletenessN/A
6Loan Purchased by InstitutionN/A
Code 2 vs Code 4: Code 2 = lender APPROVED, borrower declined AFTER approval. Code 4 = borrower withdrew BEFORE lender made a decision. The key: who stopped the process and when?

Fair Housing Act — 7 Protected Classes

Memorize All 7
FHA Protected Classes
Race · Color · National Origin · Religion · Sex · Familial Status · Disability

Familial Status = having children under 18. Disability is FHA-protected — NOT ECOA-protected.

Illegal Practices

🚫
Redlining
Refusing to lend in geographic areas based on racial composition. Detected through HMDA data analysis.
🚫
Steering
Directing buyers toward/away from neighborhoods or loan products based on protected class.
🚫
Blockbusting
Using racial change to induce panic selling. "Values will drop because minorities are moving in."

HMDA Data Collection — Face-to-Face

For in-person applications: MLO must ask borrower to self-identify race/ethnicity. If borrower declines, MLO must record BOTH the refusal AND their visual observation of apparent characteristics.

For non-face-to-face (phone/online): Visual observation impossible. Record "information not provided" if borrower declines.

FHA Advertising — Section 3604(c)

Prohibits advertising that indicates any preference based on protected classes — including through imagery alone. Using exclusively one racial group in all marketing materials violates Section 3604(c) even without explicit discriminatory language.

Familial Status — 55+ Exception

Communities qualifying under the Housing for Older Persons Act (HOPA) may restrict to residents 55+. This is a narrow, documented exemption. Must meet specific HOPA requirements.

Exam Traps — HMDA & Fair Housing

  • Code 2 vs Code 4 — most tested HMDA fact
  • Familial Status = FHA only, NOT ECOA
  • Visual observation REQUIRED for face-to-face, NOT for phone/online
  • HMDA disparity triggers investigation — not automatic violation finding
  • All-white photo models in ALL ads violates FHA 3604(c)
  • HOPA exemption is narrow — must meet specific requirements
